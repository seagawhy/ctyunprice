# 天翼云报价工具 - 项目说明

## 项目概述
面向电信云业务主管的标准化报价工具，支持天翼云全产品线快速报价、Excel导出。

## 功能特性
- **五大产品类别全覆盖**：计算、存储、网络、安全、备份
- **标准价格库内置**：无折扣，官方标准价
- **智能计算引擎**：自动计算月租/年租/三年总价
- **一键Excel导出**：标准格式，支持打印和客户报价

## 技术栈
- 纯前端实现，无需后端
- SheetJS (xlsx) 库用于Excel导出
- 响应式设计，支持PC和移动端

## 使用说明
1. 填写项目名称
2. 左侧选择产品分类
3. 中间选择产品规格和数量
4. 点击"添加"将产品加入报价单
5. 右侧实时查看报价清单
6. 点击"导出Excel"下载报价单

## 价格政策
- 所有价格为天翼云官方标准价
- 不含折扣，如需折扣请单独标注
- 支持月租、年租、三年租三种计费方式

## 适用场景
- 客户拜访快速报价
- 项目方案预算评估
- 内部成本核算
- 招投标文件制作
